# Can I Still Hack It?

A hands-on cybersecurity revision project.

The goal is simple:

Can I still recognize, investigate, exploit, and explain
a vulnerability without being given the solution?

## Labs

- DVWA
- VulnBank
- OWASP Juice Shop

## Method

Observe → Hypothesize → Test → Exploit → Explain → Remember
